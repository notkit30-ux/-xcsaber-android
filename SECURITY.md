# Security policy

Please report security problems **privately** through GitHub: *Security → Report a vulnerability* on this repository. Do not open a public issue for them.

Include what you found, the steps to reproduce it, and the Android and WebView versions. You can expect a first reply within a few days.

Things we especially care about: certificate-error handling, URL and scheme validation, private-tab data leaks, the userscript manager, and download safety.

XCSABER does not make you anonymous: websites and your network can still see your IP address.
